# nm_blockchain 学習用

Python(Flask)で作る学習用のブロックチェーンです。
ウォレット同士の送金、トランザクションプール、マイニング(Proof of Work)までを体験できます。

## セットアップ

```
pip install -r requirements.txt
```

## 起動方法(おすすめ: 管理ページ)

```
python admin_server.py
```

これだけで次の3つが自動で起動し、ブラウザで管理ページ(http://localhost:9000)が開きます。

| 起動するもの | ポート | 説明 |
|---|---|---|
| blockchain_server.py | 5000 | ブロックチェーン本体(取引の受付・マイニング) |
| wallet_server.py | 8080 | ユーザA のウォレット |
| wallet_server.py | 8081 | ユーザB のウォレット |

**終了するときは、このターミナルで `Ctrl + C`**(起動したサーバーもすべて停止します)。

### オプション

```
python admin_server.py -u 0           # 最初はユーザを起動しない
python admin_server.py -u 3           # 最初からユーザを3人起動する
python admin_server.py -p 9100        # 管理ページのポートを変える
python admin_server.py --no-browser   # ブラウザを自動で開かない
```

### 管理ページでできること

| エリア | 内容 |
|---|---|
| 01 Blockchain Node | 起動・停止 / Mine(手動マイニング) / Auto Mine(一定間隔で自動マイニング) / ブロック数・未承認取引数の表示 |
| 02 Users | ユーザの追加(名前・ポートは空欄なら自動) / Open(ウォレット画面を開く) / Restart / Delete |
| 03 Ledger | 未承認の取引(トランザクションプール)と、チェーンの中身(新しい順) |
| 04 Logs | 各サーバーのログ(送金やマイニングのログもここで確認できる) |

- 管理ページの「Open」から開いたウォレット画面は、タブのタイトルが「ユーザ名 | Wallet」になります。
- ブロックチェーンサーバーを停止すると、チェーンのデータは消えます(メモリ上にのみ保存しているため)。
- Auto Mine は一度開始すると、ブロックチェーンサーバーを停止するまで動き続けます。
- ログは `logs/` フォルダにも保存されます。

## 送金からマイニングまでの流れ

1. 管理ページでユーザA・ユーザBの「Open」を押し、それぞれのウォレット画面を開く
2. ユーザBの画面の「Blockchain Address」をコピー
3. ユーザAの画面の「Address」に貼り付け、「Amount」に金額を入れて「Send」
4. 管理ページの「Ledger」の Transaction Pool に取引が表示される
5. 管理ページの「Mine」を押すと、取引がブロックに入り Chain に追加される(マイナーには報酬 1.0)

※ ウォレット画面は開く(再読み込みする)たびに新しい鍵とアドレスが作られます。

## 手動で起動する場合

管理ページを使わずに、ターミナルを3つ開いて個別に起動することもできます。

```
python blockchain_server.py        # ポート5000
python wallet_server.py -p 8080    # ポート8080 → http://127.0.0.1:8080/ を開く → ユーザA
python wallet_server.py -p 8081    # ポート8081 → http://127.0.0.1:8081/ を開く → ユーザB
```

- `-g` を付けると接続先のブロックチェーンサーバーを変えられます(既定: `http://127.0.0.1:5000`)。
- 管理ページと手動起動を同時に使うとポートがぶつかるため、どちらか一方にしてください。

## URL 一覧

| サーバー | URL | メソッド | 内容 |
|---|---|---|---|
| ブロックチェーン | `/chain` | GET | チェーン全体 |
| ブロックチェーン | `/transaction` | GET / POST | 未承認の取引の一覧 / 取引の追加 |
| ブロックチェーン | `/mine` | GET | マイニングを1回実行 |
| ブロックチェーン | `/mine/start` | GET | 自動マイニングを開始 |
| ウォレット | `/` | GET | ウォレット画面 |
| ウォレット | `/wallet` | GET / POST | 新しいウォレット(鍵とアドレス)を作成 |
| ウォレット | `/wallet/transaction` | POST | 署名してブロックチェーンサーバーへ送金 |
| 管理ページ | `/` | GET | 管理画面(http://localhost:9000) |

## うまく動かないとき

| 症状 | 対処 |
|---|---|
| 「ポート○○は他のプログラムが使用中です」 | 手動で起動したサーバーが残っています。ターミナルを閉じるか `netstat -ano \| findstr :5000` で確認し、`taskkill /F /PID 番号` で終了 |
| 送金が「Send failed」になる | 管理ページの Logs でエラーを確認。手動起動の場合は `python diagnose.py` で原因を切り分け |
| サーバーが固まって応答しない(Windows) | サーバーの黒い画面をクリックして「選択」状態になっていないか確認。Esc キーで解除 |
| 画面のデザインが変わらない | ブラウザで `Ctrl + F5`(古いCSSが残っている) |
